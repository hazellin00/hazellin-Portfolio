# Hazel Lin — Portfolio

A personal portfolio website built from scratch with Vue 3 + Vite, showcasing marketing analytics, operations, and AI-driven growth work.

**Live site:** [hazellin00.github.io/hazellin-Portfolio](https://hazellin00.github.io/hazellin-Portfolio/)

---

## Tech Stack

- **Framework:** Vue 3 (Composition API)
- **Build tool:** Vite
- **Routing:** Vue Router 4
- **Fonts:** Inter, Libre Bodoni, Cutive Mono (Google Fonts)
- **Analytics:** Google Analytics (GA4)
- **Deployment:** GitHub Pages

## Local Development

```bash
# Install dependencies
npm install

# Start dev server at http://localhost:3000
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

This builds the site and publishes the `dist/` folder to the `gh-pages` branch.
